# Design Direction — Replit

> Derived from brand-archaeology. Source: brand-brief.json.

## Brand Truth
Replit is the loop that ships. Describe an idea → it becomes an app → it goes live → shipped → it can loop again.
Says: "Turn ideas into apps in minutes — no coding needed."
Shows: Agent writes production-ready code + full-stack infra, 100+ integrations, enterprise control.
More true: shows.

## Composition Rules
- Dark canvas is the default ground; light only on the inverse plane.
- One voltage accent (Replit violet) carries every action beat — never floods a scene.
- Kind type does the work; big confident statements, minimal photography.
- The loop lives in structure (state returns on itself), not decoration.
- Proof over claims: show the app conjured and shipped, don't assert a benefit sentence.

## Don'ts
- No generic AI slideshow (purple gradients everywhere, robot emoji).
- No fintech blue/green dashboard look.
- No retro 90s terminal green-on-black cliché.
- No founder-story navel-gazing beat.
- No static "no coding" sentence standing in for the product.

## Motion
Entry: element materializes from depth / appears (chat → app).
Pacing: fast, ship-it momentum; deliberate holds at the proof beats.
Stillness: holds are authority — the hook and the close breathe.
Anchors: a persistent status/loop element reads as the product core across states.
Brightness: a bright "it worked" flash marks success.

## Palette
- Canvas: #0D0E11 (near-black, dev-house)
- Ink: #F4F4F5 (near-white)
- Primary: #1E1E22 (raised surface)
- Accent: #6E5CE6 (Replit violet — the voltage)
- Secondary: #A1A1AA (muted text)

## Typography
- Display: Inter (or system) — heavy weight, headline work
- Mono: Roboto Mono — for the code/status moments

## Recommended Frame-Preset
Bespoke — dark Dev-house canvas. Nearest match: a dark editorial/dev preset;
none of the shipped presets carry the loop structure, so this is bespoke.

## Beat Plan (structure IS the loop)
1. IDEA  — an idea phrase materializes (0–~6s)
2. BUILD — it becomes code/app being written (agent motion) (~6–14s)
3. LIVE  — the app goes live, proof metrics surface (~14–22s)
4. SHIP  — "Shipped." + logo loop close (~22–30s), hinting back to idea
