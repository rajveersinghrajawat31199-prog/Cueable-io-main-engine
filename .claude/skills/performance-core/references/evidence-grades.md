# Evidence grades (used on every rule in the ad skills)

| Grade | Meaning | How we may use it |
|---|---|---|
| **V** | Verified against the platform's OWN documentation (URL + date recorded in the adapter) | State as fact; encode as a hard check |
| **S** | Has a cited study/dataset, or is a search-result summary of an official page we did not fetch | Use, cite, verify before it becomes a hard rule |
| **O** | Practitioner opinion or experience (e.g. Demand Curve's course) | Use as a HYPOTHESIS to test, never as a promise |
| **U** | Unsourced claim or number | Do not put in customer-facing copy; use only as a prompt for what to verify |
| **X** | Stale or contradicted | Do not use |

Rules of the house: never present O/U as fact to a customer; never promise ROI; when a rule matters for a hard check, upgrade it to V by reading the platform doc first; log the source and date.
