# Feature Announcement Template

Use this template for launching new features or product updates.

## Prompt Template

```
Create a [DURATION] feature announcement video for [FEATURE_NAME].

Product: [PRODUCT_NAME]
Company: [COMPANY_NAME]

## Story
1. Problem: [What pain point does this solve?]
2. Solution: [How does the feature work?]
3. Result: [What impact does it have?]

## Brand
- Primary color: [#HEX]
- Secondary color: [#HEX]
- Logo: [URL]

## Metrics (if available)
- [METRIC_1]: [before → after]
- [METRIC_2]: [before → after]

## Duration
[DURATION] seconds

## CTA
[What should viewers do? Visit URL? Sign up? Try free?]
```

## Structure

A 20-second feature announcement typically follows:

```
0-2s   → Title card (feature name)
2-6s   → Problem visualization
6-12s  → Solution in action
12-16s → Impact metrics
16-20s → CTA + logo
```
