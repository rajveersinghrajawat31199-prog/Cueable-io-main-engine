# Tech Explainer Template

Use this template for explaining technical concepts, how-tos, and educational content.

## Prompt Template

```
Create a [DURATION] faceless explainer video about [TOPIC].

## Key Points to Cover
1. [POINT_1]: [explanation]
2. [POINT_2]: [explanation]
3. [POINT_3]: [explanation]

## Style
- Theme: [dark/light/gradient]
- Visual approach: [data-viz/typography/diagrams/abstract]
- Tone: [professional/educational/playful/technical]

## Audience
[Who is learning this? Beginners/intermediate/experts?]

## Duration
[DURATION] seconds
```

## Visual Approaches

| Approach | Best For |
|----------|----------|
| Data visualization | Metrics, comparisons, statistics |
| Typography-driven | Key concepts, quotes, definitions |
| Diagram/flowchart | Processes, architectures, workflows |
| Abstract graphics | Conceptual topics, theories |
| Mixed | Most explainers |

## HyperFrames Workflow

```
/faceless-explainer
```

This workflow invents all visuals from text — no website or footage needed.
