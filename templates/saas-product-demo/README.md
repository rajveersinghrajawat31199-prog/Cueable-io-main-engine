# SaaS Product Demo Template

Use this template as a starting point for SaaS product demo videos.

## Prompt Template

```
Create a [DURATION] product demo video for [PRODUCT_NAME].

Company: [COMPANY_NAME]
Website: [URL]

## What to Show
1. [FEATURE_1]: [description]
2. [FEATURE_2]: [description]
3. [FEATURE_3]: [description]

## Brand
- Primary color: [#HEX]
- Secondary color: [#HEX]
- Logo: [URL or "use text logo"]
- Style: [modern/clean/dark/playful/corporate]

## Target Audience
[Who watches this? CTOs, developers, marketers, etc.]

## Key Message
[One sentence the viewer should remember]

## Duration
[DURATION] seconds
```

## Common Durations

| Duration | Best For |
|----------|----------|
| 10-15s | Social media clips, ads, teasers |
| 20-30s | Product landing pages, email signatures |
| 45-60s | Sales decks, webinar intros |
| 90-120s | Detailed feature walkthroughs |

## HyperFrames Workflow

For SaaS demos with website capture:
```

```

For faceless demos (no website needed):
